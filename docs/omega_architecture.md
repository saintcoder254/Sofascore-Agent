# OMEGA ARCHITECTURE
Data: SofaScore -> FotMob -> Futbol24 -> Scores24 -> ESPN fallback.
Integrity: FreshnessGate -> ConflictGate -> verification -> source learning.
Intelligence: Match acquisition -> qualification -> empirical goal engine -> market models -> probability ensemble.
Decision: Market Arbiter -> adversarial layer -> calibration/consensus -> Final Arbiter.
Learning: result verification -> closed-loop learning -> source learning -> evolution -> incident audit.
NEW: empirical_goal_engine.py provides venue-conditioned empirical resampling, Poisson smoothing, and hybrid score distributions. H2H is deliberately kept separate so tiny H2H samples cannot silently contaminate the empirical goal model.


Historical failure learning: historical_failure_gate.py is a mandatory Final-Arbiter precondition. It asks 12 anti-repeat questions covering favorite traps, confidence inflation, value, double-counting, recent form, H2H, lineups, market disagreement, forced bets, empirical artifacts, Monte Carlo overconfidence, and calibration. Blockers force NO BET.
