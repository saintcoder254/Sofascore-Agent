# OMEGA 2.0 Weight Policy

1. Models below the minimum settled sample remain SHADOW.
2. Live weights require point-in-time predictions with verified outcomes.
3. Weights are based on out-of-sample probability quality, not model complexity.
4. Calibration must improve without worsening log loss before a calibration candidate can be promoted.
5. Market closing information is a benchmark and is never treated as an automatic prediction override.
6. The empirical goal engine remains quarantined until distribution-level validation demonstrates incremental value.
7. Any historical-failure BLOCK remains a hard NO BET regardless of model weight.
